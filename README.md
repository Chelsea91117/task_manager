# Task Manager

**Task Manager** — это консольное приложение для управления задачами. Оно позволяет пользователям создавать, просматривать, редактировать, удалять и искать задачи. Данные хранятся в локальном файле, что обеспечивает простоту использования.

## Функциональность

- **Просмотр всех задач:** Вывод списка всех задач с их деталями.
- **Просмотр задач по категориям:** Группировка задач по категориям.
- **Добавление задач:** Создание новой задачи с указанием заголовка, описания, категории, срока выполнения и приоритета.
- **Редактирование задач:** Изменение информации о задаче.
- **Обновление статуса:** Указание, выполнена задача или нет.
- **Удаление задач:** Удаление по ID или по категории.
- **Поиск задач:** Поиск задач по ключевым словам в заголовке, категории, приоритете или статусе.

## Используемые технологии

- **Язык программирования:** Python 3.10+
- **Структура проекта:**
  - **Модульность:** Каждый компонент (управление задачами, хранение данных, логика задач) реализован в отдельном модуле.
  - **Хранилище:** Локальное хранение данных с использованием сериализации.
